对齐要点（对比实验公平性保障）

① 数据完全对齐

所有模型读同一份 MNIST/raw 官方 IDX 文件（torchvision 约定 <root>/MNIST/raw），修复了原脚本 root='./MNIST' 会触发重复下载的隐患；传统 ML 输入由 [0,1] 统一为 [−1,1]。

② 训练协议对齐

深度模型统一 batch 64、10 epochs、Adam(1e-3)+StepLR、CE 损失、seed 42；num_workers=0（Windows）；每个实验训练前重置种子，保证初始化流一致。

③ 评估对齐

全部模型（含传统 ML）在同一份官方 10k 测试集上报 Top-1 准确率；深度模型逐 epoch 记录 loss / test acc 并绘制曲线。

④ DDPM 链路可追溯

伪标签器、置信度阈值、保留率、采样步数等全部元信息写入 ddpm_synthetic.pt 与 summary.md 的 Protocol 区，保证结论可复现、可审计。

结果分析 Analysis

状态：本轮全部实验已完成并填入（2026-09-07 · myagent 环境 · RTX 5060 · 全程约 55 分钟）。混合增广实验未纳入本轮范围（作为可选扩展，命令见复现区）。

① 深度模型架构对比 ✔

CNN 0.9931 ≫ ViT 0.9732 > ANN 0.9338。卷积归纳偏置在 28×28 小图 + 10 epochs 短训练下收益压倒性；ViT 参数最多（120 万）却落后 CNN 约 2pp 且 ep9 仍在爬升（欠训练特征，文献预期成立：ViT 需大数据/强增广）；ANN 受限于 1.2 万参数 + Sigmoid，~93% 见顶。

② 深度 vs 传统机器学习 ✔

SVM-RBF 0.9792 是被低估的强基线：反超 ViT（0.9732）与 ANN，距 CNN 仅 1.4pp；RF 0.9705、KNN 0.9688 同样压过 ViT/ANN。"深度全面占优"在 MNIST 上不成立——只有 CNN 占优，且 SVM 训练 198s（CPU 单机）vs CNN 92s（GPU），性价比看 CNN 赢、看门槛 SVM 更平易。LR 因 100 迭代未收敛，0.9225 只能当下限。

③ DDPM 生成数据质量（下游视角）✔

保留率 94.2% + CNN 仅掉 3.3pp（0.9931 → 0.9601）：只用 1,883 张合成图（真实数据量 1/32）就在真实测试集达 96%——生成样本的判别信息密度高，DDPM 生成质量整体可用。gap 排序 CNN(−3.3pp) < ViT(−16.8pp) < ANN(−26.8pp)：掉点主因是数据规模/多样性而非模型容量（容量最小的 ANN 掉最狠、对数据最敏感的 ViT 居中）；另注意上限同时受伪标签教师（CNN 自身 0.9931）限制。
